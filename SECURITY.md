# Security Policy

## Reporting a Vulnerability

We take the security of MinimalTab seriously. If you discover a vulnerability, please **do not open a public issue.** Publicly disclosing a security flaw allows it to be exploited before a fix can be implemented.

### How to Report
Please report vulnerabilities using **GitHub’s Private Vulnerability Reporting** feature:

1. Go to the [MinimalTab Repository](https://github.com/PatchyPhoenix/MinimalTab).
2. Click on the **Security** tab at the top of the page.
3. Click **Report a vulnerability** to open a private draft.

### What to Expect
* **Response Time:** We aim to acknowledge all reports within 48 hours.
* **Updates:** We will provide status updates as we work toward a resolution.
* **Disclosure:** Once a patch is released, we will coordinate a public disclosure and provide credit to the researcher.

Thank you for helping keep MinimalTab secure!
