# MinimalTab

> A minimalistic, productive, and beautiful replacement for your browser's default new tab.

MinimalTab is designed to remove distractions while providing the tools you need through a clean interface and a unique Shortcut Drawer.

## ✨ Features
* **Minimalist Design:** Focused on productivity and aesthetics.
* **Heavily Customizable:** Make it yours with deep setting options.
* **Shortcut Drawer:** A unique, tucked-away space for your most-used links.
* **Widgets:** Essential tools right where you need them.

---

## 🚀 Installation

### Chromium-based (Chrome, Brave, Opera, Edge)
1. **Download** and unzip the source code.
2. Open your browser and navigate to `chrome://extensions`.
3. Enable **Developer mode** (usually a toggle in the top right).
4. Click **Load unpacked** and select the folder containing `manifest.json`.
