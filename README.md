# <ins>MinimalTab</ins>
### An extension to replace the default new tab of your browser with a minimalistic tab
Features:
- Minimalistic, productive and beautiful
- Heavily customizable
- Unique *Shortcut Drawer*
- Widgets

## Installation:
### Chromium based Browsers (Chrome, Opera, Edge)
- Download and unzip the code
- Open the Extensions tab in your browser
- Enable developer mode
- Select "Load unpacked"
- Select the folder with "manifest.json"

### Firefox - Temporary
### Firefox - Temporary
- Download and unzip the code
- Enter the url "about:debugging"
- Select "This Firefox"
- Select "Load Temporary Add-On"
- Select "manifest.json" in the extracted folder
